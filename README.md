# Projetos Pessoais

Este repositório reúne projetos desenvolvidos durante minha jornada de aprendizado em programação. O objetivo é colocar em prática os conceitos estudados, desenvolver soluções para problemas reais e acompanhar minha evolução como desenvolvedor.

## Conteúdos aplicados

- Lógica de Programação
- Algoritmos
- Estruturas de Controle
- Estruturas de Dados
- Otimização de Código
- Manipulação de Arquivos
- Modularização
- Tratamento de Exceções
- Versionamento com Git e GitHub
